# 数学公式验证与可视化

数学公式的数值验证与可视化项目，每个文件夹独立运行，均包含 Python 脚本、生成的图像和各自的 README 说明。

## 目录结构

| 文件夹 | 说明 |
| --- | --- |
| `斐波拉契数列/` | 验证斐波那契数列相邻项比值 `F(n-1)/F(n)` 是否落入目标区间，并绘制其震荡收敛到黄金分割倒数 `1/φ ≈ 0.618` 的图像。 |
| `Stirling/` | 分析基础 Stirling 近似 `n! ≈ √(2πn)·(n/e)^n` 的精度，验证误差量级 `1/(12n)` 并绘图。 |
| `Wallis/` | 分析 Wallis 无穷乘积逼近 `π/2` 的精度，验证误差量级 `1/(4n)` 并绘图。 |

## 依赖

- Python 3
- `matplotlib`（绘图）
- `mpmath`（Stirling、Wallis 高精度计算）
- 标准库 `decimal`（斐波那契高精度计算）

## 运行

进入对应文件夹，运行其中的 `plot_*.py` 脚本即可生成图像，例如：

```bash
cd Stirling
python plot_basic.py
```

各文件夹内的 README 有更详细的公式推导、数值结果和图像说明。
